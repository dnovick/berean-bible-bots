# Ch30 Qal–Piel Contrast Drill

Students compare 17 Piel verb forms against their Qal counterparts, translating each Piel and naming its semantic function (Intensive, Factitive, Iterative, Denominative, or Simple Action). The exercise is organized by function category — Part A (Intensive, 7 items), Part B (Factitive from stative roots, 5 items), and Part C (Simple Action and Denominative, 5 items) — so that students can see the pattern within each category before moving to the next. All forms are attested in the OT, drawn primarily from Genesis 1–43, Exodus, and Leviticus.
