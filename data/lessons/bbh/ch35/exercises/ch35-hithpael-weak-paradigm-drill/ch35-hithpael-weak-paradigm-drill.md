# Ch35 Hithpael Weak Paradigm Drill — Hithpael Weak

**Root:** גלה (Part A) / צדק (Part B) / נחם (Part C) / ברך (Part D) | **Stem:** Hithpael

**Instructions:** Write the Hithpael Weak forms. Part A uses גלה (III-ה). Part B shows the metathesis rule: when R1 = ז, צ, שׁ, or שׂ, the הִתְ prefix undergoes metathesis (הִצְטַדֵּק). Part C uses נחם (II-Guttural, Virtual Doubling — §35.6-7). Part D uses ברך (II-Guttural, Compensatory Lengthening — §35.8-9).
