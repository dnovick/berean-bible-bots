# Ch30 Stem Identification Drill (Strong Roots)

Students identify the stem, conjugation, PGN, and root for 24 Hebrew verb forms from strong roots (קטל, דבר). Four stems are represented — Qal, Niphal, Hiphil, and Piel — with particular emphasis on distinguishing the Piel's dagesh forte in R2 from superficially similar forms in other stems. The drill systematically works through the paradigm of a single root (דבר, items 5–24) so students can see how the same root looks in every stem and conjugation simultaneously.

## Coverage

| Stem | Forms | Key Markers Drilled |
|---|---|---|
| Qal | 7 | No prefix; basic a–a perfect; standard imperfect vowels; holem participle |
| Niphal | 5 | נִ prefix (perfect); assimilated נ with dagesh (imperfect/participle) |
| Hiphil | 5 | הִ prefix + chirik/yod chain; patach in wayyiqtol/participle prefix |
| Piel | 7 | Dagesh forte in R2; ִ–ֵ perfect; ְ–ַ–ֵ imperfect; מְ participle prefix |
