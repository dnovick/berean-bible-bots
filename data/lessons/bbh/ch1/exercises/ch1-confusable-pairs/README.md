# ch1-confusable-pairs — Hebrew Confusable Letter Pairs Drill

[← Back to Chapter 1](../../README.md)

## Description

A side-by-side discrimination drill covering the 14 most commonly confused Hebrew letter pairs, including sofit/standard pairs. For each pair, students provide the name of both letters and state the key visual feature that distinguishes them.
