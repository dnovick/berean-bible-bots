## Key Concepts

| Term | Definition |
|---|---|
| Masoretic Text (MT) | The standard Hebrew Bible text, produced by the Masoretes (6th–10th c. AD) |
| BHS (*Biblia Hebraica Stuttgartensia*) | The standard critical edition of the Hebrew Bible; based on the Leningrad Codex |
| Leningrad Codex | Oldest complete manuscript of the Hebrew Bible (1008/09 AD) |
| Masorah | System of marginal notes safeguarding textual accuracy |
| Masorah parva | Marginal word-statistics and Kethiv-Qere signals (outer margins) |
| Masorah magna | Expanded marginal notes (top/bottom margins; Mm register in BHS) |
| Kethiv (כְּתִיב) | "What is written" — the consonantal text |
| Qere (קְרֵי) | "What is to be read" — the Masoretic correction |
| Athnach | Major disjunctive accent marking the first half-verse pause |
| Silluq | Major disjunctive accent marking the end of a verse |
| Sof Pasuq (׃) | End-of-verse marker (equivalent to a period) |
| Pausal forms | Spelling variants that appear at Athnach and Silluq |
| Tanak | Acronym for תּוֹרָה + נְבִיאִים + כְּתוּבִים — the three divisions of the Hebrew Bible |
