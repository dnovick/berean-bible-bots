## Exercise II: Bible Translation — Imperfects with Waw Consecutive

Translate the following biblical texts. Know the parsing information for all verbs.

1. וַיְהִי רָעָב בָּאָרֶץ וַיֵּרֶד אַבְרָם מִצְרַיְמָה (Gen 12:10)
2. וַיִּשְׁמַע אֱלֹהִים אֶת־נַאֲקָתָם (their groaning) וַיִּזְכֹּר אֱלֹהִים אֶת־בְּרִיתוֹ אֶת־אַבְרָהָם אֶת־יִצְחָק וְאֶת־יַעֲקֹב (Exod 2:24)
3. וַיִּבֶן יְהוָה אֱלֹהִים אֶת־הַצֵּלָע (rib) אֲשֶׁר־לָקַח מִן־הָאָדָם לְאִשָּׁה (Gen 2:22)
4. וַיְהִי אַחֲרֵי הַדְּבָרִים הָאֵלֶּה וַיָּמָת יְהוֹשֻׁעַ בִּן־נוּן עֶבֶד יְהוָה בֶּן־מֵאָה וָעֶשֶׂר שָׁנִים (Josh 24:29)
5. וַיָּקָם מֶלֶךְ־חָדָשׁ (new) עַל־מִצְרָיִם אֲשֶׁר לֹא־יָדַע אֶת־יוֹסֵף (Exod 1:8)
6. וַיָּבֹא מֹשֶׁה בְּתוֹךְ הֶעָנָן וַיַּעַל אֶל־הָהָר וַיְהִי מֹשֶׁה בָּהָר אַרְבָּעִים יוֹם וְאַרְבָּעִים לָיְלָה (Exod 24:18)

## Exercise IV: Bible Translation — Perfects with Waw Consecutive

Translate the following biblical texts. Know the parsing information for all verbs.

1. וְכָתַבְתָּ עַל־הָאֲבָנִים אֶת־כָּל־דִּבְרֵי הַתּוֹרָה הַזֹּאת (Deut 27:8)
2. וִישַׁבְתֶּם בָּאָרֶץ אֲשֶׁר נָתַתִּי לַאֲבֹתֵיכֶם וִהְיִיתֶם לִי לְעָם וְאָנֹכִי אֶהְיֶה לָכֶם לֵאלֹהִים (Ezek 36:28)
3. וְנָתַתִּי לָכֶם לֵב חָדָשׁ (new) וְרוּחַ חֲדָשָׁה אֶתֵּן בְּקִרְבְּכֶם (Ezek 36:26)
4. וְאָהַבְתָּ אֵת יְהוָה אֱלֹהֶיךָ וְשָׁמַרְתָּ מִשְׁמַרְתּוֹ וְחֻקֹּתָיו וּמִשְׁפָּטָיו וּמִצְוֹתָיו כָּל־הַיָּמִים (Deut 11:1)
5. וְזָכַרְתִּי אֶת־בְּרִיתִי אֲשֶׁר בֵּינִי וּבֵינֵיכֶם וּבֵין כָּל־נֶפֶשׁ חַיָּה בְּכָל־בָּשָׂר וְלֹא־יִהְיֶה עוֹד הַמַּיִם לְמַבּוּל (Gen 9:15) (for a flood)
6. וְנָתַתִּי לְךָ וּלְזַרְעֲךָ אַחֲרֶיךָ אֵת אֶרֶץ מְגֻרֶיךָ (your sojournings) אֵת כָּל־אֶרֶץ כְּנַעַן לַאֲחֻזַּת (for a possession) עוֹלָם וְהָיִיתִי לָהֶם לֵאלֹהִים (Gen 17:8)
