# Ch30 Piel Paradigm Drill

Students produce the complete Piel paradigm for the strong root דבר across six conjugation types. The exercise reinforces the defining Piel marker — dagesh forte in R2 — and the characteristic Piel vowel patterns in the perfect (ִ–ֵ), imperfect (ְ–ַ), imperative, infinitives, and participle. An answer key for each part is included at the bottom of the static file.
