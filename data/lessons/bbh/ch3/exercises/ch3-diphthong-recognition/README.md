# Ch3 Diphthong Recognition Exercise

Identify the diphthong combination in 12 Hebrew words, or recognize when a word has none.

## Exercise

| Exercise | Description |
|---|---|
| Ch3 Diphthong Recognition | For each word: identify the diphthong combination (Pathach + Yod, Qamets + Yod before Waw, Holem + Yod, Shureq + Yod) or "none." 12 words with answer key. |
