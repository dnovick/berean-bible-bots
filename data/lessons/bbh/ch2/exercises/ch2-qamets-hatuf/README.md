# Exercise: Qamets or Qamets Hatuf?

**Chapter:** BBH Ch2 — Hebrew Vowels
**Topic:** Distinguishing long A (Qamets) from short O (Qamets Hatuf)

## Description

Students analyze 12 Hebrew words containing the T-bar vowel sign and determine whether it represents Qamets (long A) or Qamets Hatuf (short O) by examining syllable type, accent, and metheg presence.

**Rule:** Qamets Hatuf occurs only in a *closed*, *unaccented* syllable with *no* metheg.

Items alternate evenly between Qamets and Qamets Hatuf answers.
