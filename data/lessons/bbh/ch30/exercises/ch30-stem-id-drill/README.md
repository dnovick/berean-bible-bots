# Ch30 Stem Identification Drill (Strong Roots)

Students identify the stem, conjugation, PGN, and root for 24 Hebrew verb forms from strong roots (קטל, דבר, שׁמר, כבד). All five stems studied through Ch30 — Qal, Niphal, Hiphil, Hophal, and Piel — are represented, with particular emphasis on distinguishing the Piel's dagesh forte in R2 from superficially similar forms in other stems. The drill systematically works through the paradigm of a single root (דבר, items 5–24) so students can see how the same root looks in every stem and conjugation simultaneously.
