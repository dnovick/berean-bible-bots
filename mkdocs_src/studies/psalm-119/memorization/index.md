# Psalm 119 — Memorization Exercises

Per-section memorization resources for all 22 acrostic stanzas. Each section provides:

- **Vocabulary deck** — key words from the section with verse references (Anki)
- **Verse-recitation deck** — line-starter and English→Hebrew cards (Anki)
- **Cloze exercise — Level 1** — key vocabulary words blanked (HTML / PDF)
- **Cloze exercise — Level 2** — last word of each line blanked (HTML / PDF)
- **Verse-ordering exercise** — restore the 8 verses to canonical order (HTML / PDF)
- **First-word-prompt exercise** — given the first word, complete the verse (HTML / PDF)
- **Reference card** — Hebrew + KJV side-by-side, printable (PDF)
