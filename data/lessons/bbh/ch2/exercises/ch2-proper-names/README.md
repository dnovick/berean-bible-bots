# Exercise: Sounding Out Proper Names

**Chapter:** BBH Ch2 — Hebrew Vowels
**Topic:** Vowel identification in biblical proper names

## Description

Students examine 15 familiar biblical proper names and identify every vowel sign in left-to-right order (by BBH name), then note whether any matres lectionis (waw, yod, or he functioning as a vowel holder) are present.

Names covered: שָׂרָה (Sarah), נֹחַ (Noah), דָּוִד (David), רוּת (Ruth), לֵאָה (Leah), מֹשֶׁה (Moses), יַעֲקֹב (Jacob), יִצְחָק (Isaac), אַהֲרֹן (Aaron), מִרְיָם (Miriam), שְׁלֹמֹה (Solomon), אֱלִיָּהוּ (Elijah), יוֹסֵף (Joseph), אַבְרָהָם (Abraham), יְרוּשָׁלַיִם (Jerusalem).
