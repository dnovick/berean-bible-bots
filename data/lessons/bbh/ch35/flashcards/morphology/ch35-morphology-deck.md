# Chapter 35 — Hithpael Weak Morphology Deck

> **Scope note:** This deck provides diagnostic-highlights coverage — not all PGN forms for every conjugation. For full paradigm practice across all PGN slots, use the paradigm drill exercise.

34 cards covering 4 roots across the main Hithpael weak verb classes, with diagnostic cards for phonological phenomena (metathesis, virtual doubling, compensatory lengthening, I-נ non-assimilation).

**Weak classes covered:**
- **פלל** (Geminate) — to pray — most common Hithpael verb in the OT
- **גלה** (III-ה) — to reveal oneself
- **נחם** (II-Guttural virtual doubling / I-נ) — to relent, be consoled
- **ברך** (II-Guttural compensatory lengthening) — to bless oneself, be blessed

## Key Diagnostic Summary

| Card Front | Expected Back |
|---|---|
| Hithpael Wayyiqtol prefix | וַיִּתְ (waw-Patach + Yod-Hireq + Taw) — e.g. וַיִּתְפַּלֵּל, וַיִּתְנַחֵם |
| Geminate Hithpael: when can Dagesh in R2 drop? | Before Shewa (sqnmlwy rule) — e.g. הִתְפַּלְלוּ (Perf 3cp); Pathach under R1 + undoubled R2 retained |
| II-Guttural virtual doubling in Hithpael: what changes? | No Dagesh in R2 (guttural rejects it); Pathach under R1 preserved; guttural takes Patach or Hateph-Patach |
| II-Guttural compensatory lengthening in Hithpael: what changes? | ר rejects Dagesh; Pathach under R1 lengthens to Qamets; rely on הִתְ/יִתְ/מִתְ prefixes for stem ID |
| III-ה Hithpael Infinitive Construct: distinctive ending? | וֹת (Holem-Waw + Taw) — e.g. הִתְגַּלּוֹת; unique to III-ה Hithpael |
| I-שׁ Hithpael: what phonological change occurs? | Metathesis — ת swaps with שׁ → הִשְׁתַּ prefix; most important: הִשְׁתַּחֲוָה (bow down/worship) from שׁחה — 173× in OT |
| I-נ in Hithpael: does נ assimilate into R2? | No — הִתְ prefix ת stands between prefix vowel and נ, blocking assimilation; e.g. הִתְנַחֵם (not *הִדַּנֵּחֵם) |
