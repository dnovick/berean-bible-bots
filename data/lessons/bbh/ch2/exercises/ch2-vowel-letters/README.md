# Exercise: Vowel Letter Identification

**Chapter:** BBH Ch2 — Hebrew Vowels
**Topic:** Matres lectionis — waw, yod, and he as vowel holders

## Description

Students examine 15 common Hebrew vocabulary words and identify: (1) whether any matres lectionis are present, (2) which letter(s) — ו (waw), י (yod), or ה (he) — and (3) what vowel each mater represents.

Vowel types covered: Holem Waw, Hireq Yod, Tsere Yod, Qamets He, Seghol He, Shureq.
