# ch1-sofit-forms — Hebrew Final (Sofit) Letter Forms Drill

[← Back to Chapter 1](../../README.md)

## Description

A 5-item identification drill covering all five Hebrew letters that have a final (sofit) form. Students are given the standard form of the letter along with its name and must select the correct sofit form from a dropdown of visually similar options.

## Letters Covered

| # | Standard Form | Name | Final (Sofit) Form | Sofit Name |
|---|---|---|---|---|
| 1 | כ | Kaf (soft) | ך | Kaf Sofit |
| 2 | מ | Mem | ם | Mem Sofit |
| 3 | נ | Nun | ן | Nun Sofit |
| 4 | פ | Pe (soft) | ף | Pe Sofit |
| 5 | צ | Tsade | ץ | Tsade Sofit |
